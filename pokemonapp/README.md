# Pokédex

Aplicativo Flutter que consulta uma API de Pokémon e apresenta uma lista com acesso à tela de detalhes.

## Personalizações desta versão

- Pesquisa local por nome ou tipo de Pokémon.
- Mensagens para lista vazia e resultados sem correspondência.
- Ajustes no tema, nos cards e no tratamento de falha ao carregar imagens.

**Adaptação:** João Pedro Cardoso. Esta pasta contém personalizações sobre o código-base recebido; mantenha os créditos do material original conforme a orientação da atividade.

## Como executar

Na pasta deste projeto, rode `flutter pub get` e depois `flutter run`. A API usada pelo app precisa estar disponível no endereço configurado em `lib/services/pokemon_service.dart`.
